# InfraGuardian

- **Autor:** Fernando Scherer
- **Repositório:** https://github.com/fernandosscherer/InfraGuardian
- **Compatibilidade:** servidores Linux de diferentes distribuições e versões; cPanel/WHM é opcional.

Ative com `Use infraguardian.`

Modos: `AUDIT`, `MAIL`, `SECURITY`, `MIGRATION`, `PERFORMANCE`, `BACKUP`, `RECHECK`, `REMEDIATION-PLAN` e `REMEDIATION`.

**Padrão:** READ-ONLY. Nenhuma alteração é executada sem autorização específica.
