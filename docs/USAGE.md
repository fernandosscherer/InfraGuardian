# Uso

1. Conecte o agente ao servidor por SSH com uma conta de privilégio mínimo.
2. Ative: `Use infraguardian`.
3. Informe o escopo: `AUDIT`, `MAIL`, `SECURITY`, `MIGRATION`, `PERFORMANCE` ou `BACKUP`.
4. A auditoria começa em READ-ONLY.
5. Para correções, solicite primeiro um plano; aprove cada mudança individualmente.

Exemplo: `Use infraguardian para auditar este servidor Linux, identificar distribuição e serviços, verificar riscos de spam e entregar um relatório. Não faça alterações.`
